Marcas de cliente

Aquí se marca a un cliente por su teléfono. La marca incluye una nota de texto y uno o varios habilitadores que se prenden o se apagan, como «No desea Rappi Cargo» o «Posible fraude». Cuando se elige a ese cliente al tomar un pedido (en el web y en el POS), el sistema muestra la marca. Si el habilitador bloquea Rappi Cargo, el sistema no deja enviar su pedido por ahí. Solo pueden usarla los administradores.

No tiene permiso para esta pantalla. Solo los usuarios con rol de administrador pueden marcar clientes.

Los habilitadores son los interruptores que se le pueden prender a un cliente. Aquí se crean nuevos y se decide qué hace cada uno. Bloquea Rappi Cargo: el sistema se niega a enviar por Rappi Cargo el pedido de un cliente que lo tenga prendido. Si no lo bloquea, solo avisa. Un habilitador que se desactiva deja de mostrarse y de bloquear, pero las marcas ya puestas no se pierden.
